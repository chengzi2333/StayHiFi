## 裁决表（Flutter → Compose 映射，实现者照此执行，勿自行发明）

| 原作机制 | Compose 对应 |
|---|---|
| `SpringDescription.withDampingRatio(mass,stiffness,ratio)` | `spring(dampingRatio=ratio, stiffness=stiffness)` —— 参数 1:1 直搬（press: stiffness 311/ratio 0.593；follow: 1024/0.9；jelly: 100/0.4） |
| `withDurationAndBounce(duration, bounce)` | 近似换算 stiffness=(2π/秒)²、ratio≈1−bounce×1.4（下限 0.05）：travel 400ms/b.15→stiffness 247/ratio 0.79；lift 250ms/b0→632/1.0；settle 500ms/b.32→158/0.55；fade 200ms/b0→987/1.0。手感近似即可，真机微调可接受 |
| `_Spring`（自定 Ticker 弹簧） | `Animatable<Float, AnimationVector1D>`；透镜速度读 `Animatable.velocity`（果冻变形需要） |
| `_rubberBand(overshoot, limit)` | 公式逐字搬：`1 - 1/(|x|·0.55/limit + 1)` 再乘 limit·sign |
| `_dockLayout(span,count)` 间距公式 | 逐字搬（pitch/lens/inset 三分量，含 minLensWidth=84dp 分支） |
| `RenderProxyBox` 透镜裁剪双层绘制 | items Row 画两遍：底层原色（onSurfaceVariant），上层 `clipPath(lens矩形, pill)` + 整体 tint primary + `graphicsLayer` 放大 `1+0.16·lift`；用两个 Box 层叠即可，不必手写 Layout |
| `ElasticPress` 整栏膨胀+橡胶带 | 整栏 `graphicsLayer { scaleX/scaleY/translationX }` 由 Animatable 弹簧驱动；按下 swell→1/8 膨胀，拖动超限 `_rubberBand` 平移 |
| `VelocityTracker` + fling ±1 | Compose `VelocityTracker`（`androidx.compose.ui.input.pointer.util.VelocityTracker`）；甩动方向最多越过当前项 ±1 个，越界 clamp |
| `HapticFeedback.selectionClick()` | `LocalHapticFeedback.performHapticFeedback(HapticFeedbackType.TextHandleMove)`（每越过一个 item 触发一次） |
| `kTouchSlop` 拖动阈值 | `ViewConfiguration.touchSlop`（`LocalViewConfiguration.current.touchSlop`） |
| HCT 调色（secondary tone 90 浅 / tone 4 深，alpha 0.85） | 直接用 `colorScheme.secondaryContainer` 加 alpha 0.85（M3 标准 scheme 下 tone 90/4 即 secondaryContainer）；不引 hct 依赖 |

| hover/parallax/glow（鼠标特性） | **不移植**（触屏无鼠标 hover；已在账本记 Ruling） |
| LiquidGlass | **不移植**（方案 A 裁决：玻璃换浮层） |
| Tooltip 长按提示 | 不移植（移动端无必要） |
| label 超宽缩字号（min 9sp） | 移植（`TextPainter` 预量 → Compose 用 `SubcomposeLayout` 过重，改用固定 pitch 预算内 `maxLines=1 + TextOverflow.Ellipsis`，字号恒 10sp；中文 label 2 字永不超宽，缩放逻辑 YAGNI 不搬） |

### Task 20 追加（用户反馈"点按无气泡感/软弹不对"，2026-10-21 二轮深挖）
- **F-A 气泡语义缺失（核心）**：原作 `ElasticPress._release` 松手时**不**把 swell 弹回——`_releasing=true` 后由 `_settle` 监听：swell 升到 ≥_liftSnap(0.975) 才 springTo(0)（注释明言 "it rises all the way first, as UIKit lifts the tab bar's lens all the way on a tap"）。我方 `DockController.release()` 立即 `retarget(swell, 0, PressSpring)` → 快速点按膨胀被掐断 → 气泡感消失。修法：release() 移除 swell 归零；加 `released` 标志 + settle 监听（snapshotFlow 或复用现有 lift 监听）：released && swell≥0.975 时才 swell→0。与透镜 lift 的 checkDropLift 并列。
- **F-B travel 弹簧阻尼比修正**：Flutter `SpringDescription.withDurationAndBounce` 官方公式 = stiffness (2π/T)²·m、damping 4π(1−b)m/T → **dampingRatio = 1−bounce**。travel 400ms/bounce 0.15 → 正确 ζ=0.85（现网 0.79 错了，回弹过量）。stiffness 247 不变。lift/track 的 ζ=1.0 原本就对。裁决表中"ratio≈1−bounce×1.4"换算行作废，以此为准。
- 顺带核对原作 `_press`/`_release` 时序无其他漏项（fling 顺序、dropLift 条件已验过，不必重复）。

## Task 21：动画引擎重写——SpringValue 忠实移植 _Spring（拖拽失灵根因）
- 根因：retarget 每 Move 事件 `job.cancel()+scope.launch{animateTo()}`，120Hz 事件流下动画协程拿不到首帧即被取消 → 拖动全程透镜不推进。
- 修法（忠实移植原作 `_Spring`，navigation_dock.dart L150-217）：
  - 新增 `SpringValue`：`value`/`target` 用 `mutableFloatStateOf`（快照可观察，draw 阶段读取兼容）；`springTo(target, spec)` = 读当前速度 → `TargetBasedAnimation(spec, Float.VectorConverter, currentValue, target, currentVelocity)` 重建动画对象 + 记 `startNanos = System.nanoTime()`，**不起协程**；`jumpTo(value)` 清动画对象
  - DockController 五个 Animatable 全换 SpringValue；删掉所有 slot/Job/scope
  - 单一常驻帧循环（NavigationDock 的 LaunchedEffect）：`while(true) withFrameNanos { now -> controller.onFrame(now) }`，onFrame 内对每个 SpringValue：`anim?.let { value = it.getValueFromNanos(now-start)；if (isFinishedFromNanos) { value=target; anim=null } }`
  - `velocity` 从当前 TargetBasedAnimation `getVelocityFromNanos` 读（果冻与 retarget 初速度都靠它）
  - 果冻监听循环与 snapshotFlow 监听（checkDropLift/checkSettleSwell/settleToSelection）保持不变
- 验证（必须做，不只跑单测）：装机后用 adb 录屏实证——`input swipe 300 3002 1140 3002 1500` 慢拖，ffmpeg 抽拖动中段帧（约 0.6s/1.0s 处），透镜必须**位于手指对应位置**（不再是钉死在起点）；快速 `input tap` 后抽帧确认气泡膨胀。验证命令与证据帧路径写进报告。
- `./gradlew testDebugUnitTest` 53/53 保持全绿 + assembleDebug。
