# StayHiFi 音质常驻

**한 번만 설정하면 계속 유지됩니다.**

헤드폰이 연결되는 순간, StayHiFi가 블루투스 오디오(A2DP 코덱) 파라미터를 이 기기에서 협상된 상한까지 자동으로 올립니다. 전 과정이 무감각하게 진행되므로, 매번 개발자 옵션을 뒤지지 않아도 됩니다.

## 이 앱이 존재하는 이유

제조사는 호환성과 전력 소모를 고려하여 블루투스 코덱을 보수적인 파라미터로 기본 설정합니다(예: SBC / 48kHz / 적응형 비트레이트). 헤드폰의 실제 성능을 최대로 끌어쓰려면 기존에는 다음과 같이 해야 했습니다.

- 연결할 때마다 **개발자 옵션**에 들어가 코덱 / 샘플링 레이트 / 비트 뎁스를 수동으로 조정해야 했고,
- 연결 해제 시나 개발자 옵션 종료 시 **설정이 되돌아가**므로, 매일 다시 해야 했습니다.

StayHiFi는 정확히 한 가지만 합니다. 헤드폰이 연결되는 순간, 파라미터를 되돌려 써 넣는 것입니다.

## 작동 원리

**Shizuku 또는 Stellar**(둘 중 하나)를 통해 shell 수준 권한을 얻은 뒤, 시스템 블루투스 스택의 숨겨진 `setCodecConfigPreference()` 인터페이스를 **리플렉션으로 호출**하여 A2DP 코덱 설정을 기록합니다.

- 시스템을 **패치하지 않고**, 숨겨진 코덱을 해금하지 않으며, 하드웨어에서 협상된 능력 상한을 넘기지 않습니다.
- 상시 표시되는 포그라운드 서비스가 연결 이벤트만 감시하므로, 추가 배터리 소모가 거의 없습니다(폴링 루프 없음).
- 앱에 파라미터 목표 템플릿이 저장되어 있지 않습니다. 「최대치로 맞추기」 목표는 헤드폰 × 휴대폰 × ROM 조합에 맞춰 **그 자리에서 파생**됩니다(기능 마스크 최대값 + 코덱별 내장 최적 등급 테이블), 기록 후에는 설정을 **다시 읽어 검증**합니다.

### 상태 모델: 두 가지 상태

홈 화면 상태 카드는 정확히 두 가지 상태 중 하나만 표시합니다.

- **아직 최대치가 아님** — 현재 협상된 파라미터가 이 휴대폰의 최대치보다 낮고, 연결 시 StayHiFi가 이를 끌어올립니다.
- **본 기기 최고 음질 출력 도달** — 협상된 설정이 파생된 목표와 이미 같으므로, 더 이상 올릴 것이 없습니다.

휴대폰 자체의 능력 상한이 바뀌면(코덱 마스크 또는 등급 테이블 갱신) 목표는 자동으로 다시 파생됩니다.

## 설치

공식 배포 채널은 이 두 곳뿐입니다(쿨안 / GitHub). 다른 출처의 APK는 설치하지 마십시오.

- **쿨안(쿨앱)**: 앱 마켓 내에서 「音质常驻(음질 상시)」 검색
- **GitHub Releases**: <https://github.com/chengzi2333/StayHiFi/releases> (릴리스 페이지에 APK SHA-256이 첨부되어 있습니다. 설치 전 반드시 확인하십시오)

필수 조건: **Shizuku** 또는 **Stellar** 매니저를 설치하고 안내에 따라 활성화하십시오(무선 디버깅 / 유선 adb 활성화, 루트 불필요).

패키지명: `com.chengzi.stayhifi`.

## 사용 방법

1. 처음 실행 시 **온보딩 5단계 가이드**를 따라 하십시오. 권한 캐리어 선택(Shizuku / Stellar) → 권한 부여 → 헤드폰 연결 → 파라미터 출처 선택 → 상시 유지 설정
2. 상시 유지 설정 「세 가지 문턱」(중국산 ROM의 백그라운드 강제 종료가 엄격하므로, 모두 설정해야 안정적입니다):
   - **자동 실행 허용**(시스템 설정 → 애플리케이션 관리)
   - **배터리 화이트리스트 등록**(배터리 최적화 끄기)
   - **백그라운드 높은 전력 사용 허용 + 최근 앱 카드 고정**: 설정 → 배터리 → 백그라운드 전력 관리에서 이 앱을 허용하고, 최근 앱 화면에서 카드를 아래로 끌어 「잠금」을 눌러 밀어서 종료되는 것을 방지하십시오
3. 그 이후는 평소처럼 사용하시면 됩니다. 헤드폰이 연결되면 파라미터가 자동으로 최대치로 맞춰지고, 알림 영역에 무음 상시 알림이 유지됩니다(옵션으로 실시간 파라미터 표시 가능).

새 기기 적응: 별도의 템플릿이 필요 없습니다. 앱이 헤드폰 × 휴대폰 × ROM 조합에 맞춰 목표를 그 자리에서 파생하며(코덱별 내장 최적 등급 테이블), 기록 후 다시 읽어 검증합니다. 온보딩의 「기록 마법사」는 진단 도구로, 현재 파라미터를 한 번 캡처하여 본 기기의 기록으로 저장합니다(최대치 맞추기 판단에는 반영되지 않습니다).

## 개인정보 보호

- **데이터 수집 제로**: 모든 데이터는 본 기기에만 저장되며, 네트워크 업로드·통계 수집·계정 체계가 없습니다.
- 유일한 외부 상호작용은 Shizuku / Stellar와의 로컬 IPC입니다.

## 면책 조항

본 프로젝트는 **Shizuku, Stellar, OPPO, vivo** 및 그 계열사와 아무런 소속·후원·공인 관계가 없으며, 모든 상표는 각 소유자의 것입니다. 본 앱은 **본인 기기에서만** 시스템 숨겨진 인터페이스(리플렉션 호출)의 파라미터를 조정합니다. 리스크는 스스로 평가하십시오.
