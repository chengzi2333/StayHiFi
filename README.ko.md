## 왜 StayHiFi가 필요한가

제조사는 호환성과 전력 소모를 고려해 블루투스 코덱을 보수적인 기본값으로 설정합니다(SBC / 48kHz / 적응형 비트레이트)——HiFi 값을 내고 MP3 소리를 듣는 셈입니다. 헤드폰의 실제 성능을 최대로 끌어쓰려면 연결할 때마다 **개발자 옵션**에 들어가 코덱 / 샘플링 레이트 / 비트 뎁스를 수동으로 조정해야 하고, **연결 해제 시나 개발자 옵션을 닫으면 설정이 되돌아가**므로 매일 다시 시작해야 했습니다.

StayHiFi가 이 귀찮은 일을 대신합니다. 헤드폰이 연결되는 순간, 파라미터를 이 기기가 협상해 낸 상한까지 되돌려 써 넣는 것——전 과정이 무감각하게 진행됩니다. 최대치로 올렸는데 무음이 나거나 잡음이 섞이거나, 그냥 취향대로 조정하고 싶다면 사용자 지정 음질에서 코덱 / 샘플링 레이트 / 비트 뎁스 / 비트레이트를 수동으로 낮추고 한 번의 탭으로 적응형으로 되돌릴 수 있습니다.

## 주요 기능

- **연결 즉시 최대치**: 어떤 블루투스 헤드폰과도 별도 적응 불필요——목표 파라미터는 헤드폰 × 휴대폰 × ROM 조합에 맞춰 그 자리에서 파생되며, 기록 후 다시 읽어 검증합니다. 트리거 병합과 연결 해제 보호로 재연결과 재생 시작이 더 안정적입니다
- **있는 그대로 보여주는 상태 카드**: 「본 기기 최고 음질 출력 도달」/ 「아직 최대치가 아님 · 버튼으로 재시도」/ 「사용자 지정 파라미터 적용 중」/ 「연결됨, 권한 부여 후 사용 가능」——과장 없이 사실만 표시합니다
- **재연결 시 자동 재설정**: 포그라운드 서비스가 연결 이벤트만 감시하므로 배터리 소모가 거의 없습니다(폴링 루프 없음)
- **사용자 지정 음질**: 코덱 / 샘플링 레이트 / 비트 뎁스 / 비트레이트를 현재 연결이 지원하는 범위에서 수동으로 조정할 수 있습니다. 최대치에서 무음이나 잡음이 나면 한 단계 낮추거나 한 번의 탭으로 적응형으로 복귀하십시오. 회색으로 표시된 항목은 현재 휴대폰이나 헤드폰이 지원하지 않는 것입니다. 사용자 지정 상태는 「사용자 지정」으로만 표시되며 절대 최대치인 척하지 않습니다——자동 최대치화 기본 규칙은 그대로입니다
- **코덱 정체·실시간 진단**: 본 기기에 실제로 적용된 코덱이 무엇인지 확인하고 실시간 전송 비트레이트를 표시합니다. 일부 기기에서는 고정 비트레이트도 적응형으로 동작하므로 실시간 표시를 기준으로 삼으십시오
- **상시 무음 알림 + QS 타일**: 옵션으로 실시간 파라미터 표시; QS 타일은 한 번의 탭으로 재적용을 트리거하고, 연결된 기기가 없으면 앱을 엽니다
- **iOS 스타일 플로팅 Dock 네비게이션**: 스프링 렌즈 + 젤리 변형 물리 모션
- **현재 파라미터 기록**: 기기 페이지의 진입점에서 현재 협상된 파라미터를 한 번 캡처해 보관하고, 기종/Android 버전 출처를 첨부합니다. 기종명은 오프라인에서도 확인 가능합니다(v1.2.2)
- **언제든 원클릭 복원**: 기기 페이지에서 파라미터를 처음 최대치로 올리기 전의 원래 협상 값으로 되돌려 쓸 수 있습니다
- **Material You**: 동적 색상 추출, 라이트/다크 테마가 시스템을 따름

## 작동 원리

**Shizuku 또는 Stellar**(둘 중 하나, 루트 불필요)를 통해 shell 수준 권한을 얻습니다. 이미 루팅된 기기에서는 대신 **Root 채널(실험)**을 선택할 수 있으며 언제든 되돌릴 수 있습니다. 그 뒤 시스템 블루투스 스택의 숨겨진 `setCodecConfigPreference()` 인터페이스를 **리플렉션으로 호출**하여 A2DP 코덱 설정을 기록합니다.

- 시스템을 **패치하지 않고**, 숨겨진 코덱을 해금하지 않으며, 하드웨어에서 협상된 능력 상한을 넘기지 않습니다——Root는 권한 통로만 바꿀 뿐 음질 상한을 높이지 않습니다
- Root 채널의 기기 커버리지는 아직 외부 샘플을 수집 중이며 안정 지원으로 선언하지 않습니다. 문제가 있으면 피드백을 보내 주십시오
- 시스템 블루투스 연결과 권한 읽기는 분리되어 있습니다. 권한 없이도 본 기기의 A2DP 연결과 헤드폰 이름은 볼 수 있으며, 상세 파라미터 조회와 기록은 권한이 필요합니다
- 기능상 유일한 외부 상호작용은 Shizuku / Stellar / Root와의 로컬 IPC이며, 유일한 네트워크 요청은 GitHub Releases 버전 확인입니다

## 설치

> ⚠️ 현재 공식 배포 채널은 **GitHub Releases**뿐입니다(쿨안 등록 진행 중). 다른 출처의 APK는 설치하지 마십시오.

1. 권한 준비(둘 중 하나): **Shizuku** 또는 **Stellar** 매니저를 설치하고 안내에 따라 활성화하십시오(무선 디버깅 / 유선 adb, 루트 불필요). 이미 루팅된 기기는 앱 안에서 실험 Root 채널로 바꿔 쓸 수 있습니다
2. [GitHub Releases](https://github.com/chengzi2333/StayHiFi/releases)에서 APK 다운로드——**단일 패키지로 모든 기기에 통용**되므로 ABI 버전을 고를 필요가 없습니다. 릴리스 페이지에 SHA-256과 서명 인증서 지문이 첨부되어 있으니 설치 전 확인하십시오

요구 사항: Android 10+.

## 사용 방법

1. 처음 실행 시 **온보딩 4단계 가이드**를 따라 하십시오. 권한 방식 선택 → 권한 부여 → 헤드폰 연결 → 상시 유지 설정. 연결이 이상하면 연결 단계의 「문제 해결 로그」 진입점에서 바로 로그를 보고 복사해 피드백하실 수 있습니다
2. 상시 유지 「세 가지 문턱」(중국산 ROM의 백그라운드 강제 종료가 엄격하므로, 모두 설정해야 안정적입니다):
   - **자동 실행 허용**(시스템 설정 → 애플리케이션 관리)
   - **배터리 화이트리스트 등록**(배터리 최적화 끄기)
   - **백그라운드 높은 전력 사용 허용 + 최근 앱 카드 고정**: 설정 → 배터리 → 백그라운드 전력 관리에서 이 앱을 허용하고, 최근 앱 화면에서 카드를 아래로 끌어 「잠금」을 눌러 밀어서 종료되는 것을 방지하십시오
3. 그 이후는 평소처럼 사용하시면 됩니다. 헤드폰이 연결되면 파라미터가 자동으로 최대치로 맞춰지고, 홈 상태 카드가 실시간으로 최고 음질에 도달했는지 알려줍니다. 미세 조정은 홈의 「사용자 지정 음질」에서 현재 연결이 지원하는 범위로 수동 조정하고, 이상이 생기면 낮추거나 한 번의 탭으로 적응형으로 복귀하십시오. 권한이 없어도 연결된 헤드폰 이름은 보이며, 파라미터 표시와 기록은 권한 부여 후에 이루어집니다

## 제거(언인스톨)

기록된 파라미터 환경 설정은 시스템 블루투스 스택에 지속 저장되므로, **앱을 제거해도 자동으로 복원되지 않습니다**. 기본값으로 돌아가려면 제거 전에 기기 페이지에서 「기본 파라미터 복원」을 눌러, 처음 최대치로 올리기 전의 원래 협상 값으로 되돌려 쓰십시오. 그 외에는 잔여물이 없습니다——시스템 파일을 건드리지 않으므로 제거하면 깨끗합니다.

## 피드백과 소통

기기 모델이 워낙 많고 제조사별 ROM 차이가 커서, 커버되지 않는 기기가 나올 수밖에 없습니다. 문제가 생기면 아무 채널로든 편하게 연락 주십시오.

- **GitHub Issues**: 버그 리포트와 기능 요청의 가장 좋은 창구입니다. 앱 내 「로그」 페이지의 「로그 복사」 출력을 첨부해 주시면 가장 큰 도움이 됩니다——로그는 자동으로 비식별화되어 MAC 주소와 기기명이 deviceN으로 치환되므로 그대로 붙여 넣으시면 되며, 원문을 다시 덧붙이지 마십시오
- **쿨안(CoolApk)**: @一般社畜橙子
- **샤오홍슈(Xiaohongshu)**: @橙橙橙子Orenji

## 개인정보 보호

- **데이터 수집 제로**: 모든 데이터는 본 기기에만 저장되며, 네트워크 업로드·통계 수집·계정 체계가 없습니다
- **유일한 네트워크 요청**은 GitHub Releases 버전 확인입니다(버전 번호 비교만 수행하며, 어떠한 기기 정보도 싣지 않습니다. 하루 최대 한 번 자동으로 조용히 확인하며, 설정 페이지에서 수동으로도 확인할 수 있습니다)
- 그 외 유일한 외부 상호작용은 Shizuku / Stellar / Root와의 로컬 IPC입니다——어떤 권한 채널을 쓰든 기기 안에서만 통신합니다

## 면책 조항

본 프로젝트는 **Shizuku, Stellar, OPPO, vivo** 및 그 계열사와 아무런 소속·후원·공인 관계가 없으며, 모든 상표는 각 소유자의 것입니다. 본 앱은 **본인 기기에서만** 시스템 숨겨진 인터페이스(리플렉션 호출)의 파라미터를 조정합니다. 리스크는 스스로 평가하십시오.
